Phoenix Australia Survey Analysis Dashboard

AI-powered automated pipeline for analyzing training evaluation surveys using the Kirkpatrick Four-Level Model. Built for Phoenix Australia, a mental health non-profit affiliated with the University of Melbourne, supporting 190+ online courses.

Multi-tier fallback architecture: Cache → Gemini AI → SBERT → Semantic similarity
Self-improving system: stores all classifications in SQLite, retrains SBERT from accumulated data
Human-in-the-loop learning: user corrections persist and improve future classifications
Question hashing for deduplication ensures instant lookup of previously seen questions
Statistical pre/post comparison with t-tests, Cohen's d effect sizes, and confidence intervals
Professional LaTeX PDF reports with sentiment analysis and theme extraction

Featured Project

Melbourne Electricity Market Analysis

End-to-end data platform built on 3 years of Victorian electricity market data. Raw data from three public APIs flows through a medallion pipeline on Azure Databricks, powers three production ML models, and surfaces as a four-page Power BI dashboard with a live FastAPI endpoint.

Medallion architecture (Bronze → Silver → Gold) on Azure Databricks with Delta Lake
Live pipeline: hourly AEMO price ingestion, nightly silver refresh, continuous production updates
Price prediction model (XGBoost) achieving R² 0.89 with $14.90 MAE on wholesale prices
Demand forecasting (CatBoost) with 2.5% MAPE and R² 0.98 on test data
Spike classifier with 0.99 ROC-AUC using Platt calibration on 12.4:1 imbalanced classes
Summer Paradox discovery: renewable generation falls on hottest days (29% vs 55% on cool days)
